# go-data-analytics

경영 데이터 분석과 데이터에 근거한 의사결정을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 지표 설계(North Star·KPI 트리), 대시보드 해석, 스프레드시트·SQL 실무, 기술통계·추론·회귀, A/B 실험과 인과추론 기초, 예측, 그리고 국내 데이터 법(가명정보, 데이터 산업진흥 및 이용촉진에 관한 기본법, 공공데이터의 제공 및 이용 활성화에 관한 법률)과 글로벌 비교를 다룹니다. 현업 관리자도 자기 업무를 예시로 배울 수 있게 만들었습니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop, 그리고 평소 쓰는 스프레드시트 프로그램(Excel·Google Sheets·Numbers)입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다. SQL 실습은 macOS에 기본으로 있는 `sqlite3`을 쓰거나, 원하면 튜터와 함께 설치하고, 원하지 않으면 스프레드시트로 같은 내용을 연습합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-data-analytics
```

**Claude Code**

```bash
cd ~/Desktop/go-data-analytics
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-data-analytics` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 어떤 업무에 쓰려는지, 데이터를 얼마나 다뤄 봤는지 짧게 묻고, 영역(지표·실무 도구·통계·데이터 법)마다 문제를 하나씩 풀어 출발점을 찾습니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 실습 데이터(예시 값)와 SQL은 튜터가 `learner/lab/`에 만들고, 실행은 내 스프레드시트·터미널에서 직접 합니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 데이터와 법령에 관해

- **실제 고객 정보나 회사 데이터를 대화에 붙여 넣지 마세요.** 튜터는 예시 데이터로 실습하고, 내 데이터는 열 이름과 건수 같은 구조만 받습니다.
- 법령 조문과 기준은 자주 바뀝니다. 튜터는 조문을 말할 때 국가법령정보센터 같은 공식 출처를 그 자리에서 확인하고, 확인하지 못하면 그렇다고 말합니다. 학습은 판단 연습이며 법률 자문이 아닙니다. 실제 결정은 회사의 법무·개인정보 보호책임자와 확인하세요.
- 근거 목록은 [curriculum/sources.md](curriculum/sources.md)에 조회일과 함께 있습니다.

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [curriculum/sources.md](curriculum/sources.md) | 국내·글로벌 근거 목록(공식 출처 URL·조회일) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 실습 데이터·SQL. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 실습 파일을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 튜터는 SQL이나 스크립트를 직접 실행하지 않습니다. 그 밖의 파일을 고치려 할 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
